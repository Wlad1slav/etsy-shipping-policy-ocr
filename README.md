# Розпізнавання політик доставки Etsy

Скрипт читає всі підтримувані зображення з `screenshots/<артикул>/`, розпізнає блоки політики доставки Etsy та створює окремий аркуш Excel для кожного скріншота. Назва аркуша відповідає назві директорії артикула. Якщо в директорії кілька скріншотів, наступні аркуші отримують суфікси `(2)`, `(3)` тощо, оскільки назви аркушів Excel мають бути унікальними.

Скрипт витягує:

- країну або регіон призначення;
- службу доставки;
- орієнтовний строк доставки;
- тип тарифу;
- ціну доставки одного товару в USD;
- ціну доставки додаткового товару в USD.

## Вимоги

- macOS із системним фреймворком Apple Vision та командою `swiftc`;
- Node.js 20 або новіший;
- залежності, встановлені командою `npm install` (для Excel використовується ExcelJS).

## Запуск

```bash
npm install
npm run extract
```

За замовчуванням результат зберігається у `outputs/shipping_policies.xlsx`.

Власні шляхи та збереження сирого результату OCR:

```bash
npm run extract -- \
  --input ./screenshots \
  --output ./outputs/shipping_policies.xlsx \
  --keep-ocr
```

Запуск тестів парсера:

```bash
npm test
```

Неповністю розпізнані рядки не видаляються, а підсвічуються в Excel статусом `Перевірити`. Це корисно для скріншотів, які починаються або закінчуються посередині блоку доставки.
